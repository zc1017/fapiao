# 发票识别工具

基于PyQt5开发的发票识别工具，支持PDF和图片格式发票的二维码识别，自动解析发票信息并导出Excel。

## 功能特点

- **多格式支持**: 支持PDF、PNG、JPG、JPEG、BMP格式发票文件
- **批量处理**: 支持多选文件、添加文件夹，批量识别发票
- **二维码识别**: 自动识别发票二维码，提取发票基本信息
- **OCR补充**: 使用PaddleOCR自动识别购买方和销售方名称、纳税人识别号
- **全电发票支持**: 支持新版全电发票格式解析
- **实时显示**: 识别一条显示一条，无需等待全部完成
- **结果可编辑**: 双击单元格可编辑识别结果
- **文件快速打开**: 双击文件名可用系统默认程序打开原文件
- **Excel导出**: 识别结果可导出为Excel文件，支持选择导出字段

## 安装

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. GPU加速（可选）

如果有NVIDIA GPU，可以安装GPU版本以加速OCR识别：

```bash
pip install paddlepaddle-gpu
```

如果有AMD GPU，可以安装ROCm版本：

```bash
pip install paddlepaddle-rocm
```

### 3. OCR模型

首次运行时会自动下载PaddleOCR模型，请确保网络畅通。

## 使用方法

### 启动程序

双击 `启动.bat` 或运行：

```bash
python invoice_app.py
```

### 操作步骤

1. **添加文件**: 点击"添加文件"或"添加文件夹"按钮，选择发票文件
2. **开始识别**: 点击"开始识别"按钮，程序会自动识别二维码并解析发票信息
3. **查看结果**: 识别结果实时显示在下方表格中
4. **编辑结果**: 双击单元格可编辑识别结果
5. **打开文件**: 双击文件名可打开原发票文件
6. **导出Excel**: 点击"导出Excel"按钮，选择需要导出的字段，保存为Excel文件

## OCR识别优化

程序使用以下图像预处理技术提高OCR识别准确度：

1. **灰度转换**: 将彩色图像转为灰度图
2. **CLAHE增强**: 自适应直方图均衡化，增强对比度
3. **降噪处理**: 使用非局部均值降噪去除噪点
4. **二值化**: 使用OTSU自动阈值二值化
5. **锐化处理**: 使用拉普拉斯算子锐化边缘

## 注意事项

1. **二维码识别**: 确保发票二维码清晰可见，模糊或遮挡可能导致识别失败
2. **OCR识别**: OCR识别需要一定时间，大批量处理请耐心等待
3. **网络要求**: 部分发票需要从URL获取XML数据，需要网络连接
4. **发票查验**: 如需在线查验发票真伪，请访问国家税务总局发票查验平台
