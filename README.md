# 发票识别工具

基于PyQt5开发的发票识别工具，支持PDF和图片格式发票的二维码识别，自动解析发票信息并导出Excel。

## 功能特点

- **多格式支持**: 支持PDF、PNG、JPG、JPEG、BMP格式发票文件
- **批量处理**: 支持多选文件、添加文件夹，批量识别发票
- **二维码识别**: 自动识别发票二维码，提取发票基本信息
- **OCR补充**: 使用EasyOCR自动识别销售方名称和纳税人识别号
- **全电发票支持**: 支持新版全电发票格式解析
- **Excel导出**: 识别结果可导出为Excel文件，包含发票信息和商品明细

## 支持的发票类型

| 类型代码 | 发票类型 |
|---------|---------|
| 01 | 增值税专用发票 |
| 04 | 增值税普通发票 |
| 10 | 电子普通发票 |
| 14 | 电子专票 |
| 32 | 全电发票（电子发票）|
| 33 | 全电发票（增值税专用发票）|

## 安装

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 安装OCR模型

首次运行时会自动下载EasyOCR模型，请确保网络畅通。

## 使用方法

### 启动程序

双击 `启动发票识别工具.bat` 或运行：

```bash
python invoice_app.py
```

### 操作步骤

1. **添加文件**: 点击"添加文件"或"添加文件夹"按钮，选择发票文件
2. **开始识别**: 点击"开始识别"按钮，程序会自动识别二维码并解析发票信息
3. **查看结果**: 识别结果显示在下方表格中
4. **导出Excel**: 点击"导出Excel"按钮，将结果保存为Excel文件

## 发票二维码格式说明

### 全电发票格式

```
版本号,发票种类,发票代码,发票号码,金额,开票日期,校验码,加密字段
例如：01,32,,26427000000316294884,100.76,20260330,,5F98
```

### 传统发票格式

```
发票类型代码,发票代码,发票号码,金额,日期,校验码
```

## 注意事项

1. **二维码识别**: 确保发票二维码清晰可见，模糊或遮挡可能导致识别失败
2. **OCR识别**: OCR识别需要一定时间，大批量处理请耐心等待
3. **网络要求**: 部分发票需要从URL获取XML数据，需要网络连接
4. **发票查验**: 如需在线查验发票真伪，请访问国家税务总局发票查验平台

## 发票查验平台
