# 发票识别工具

基于PyQt5开发的发票识别工具，支持PDF和图片格式发票的二维码识别，自动解析发票信息并导出Excel。

## 功能特点

- **多格式支持**: 支持PDF、PNG、JPG、JPEG、BMP格式发票文件
- **批量处理**: 支持多选文件、添加文件夹，批量识别发票
- **智能追加**: 新识别的发票自动追加到结果列表，不覆盖已有结果
- **重复检测**: 自动检测已识别文件，避免重复识别
- **二维码识别**: 自动识别发票二维码，提取发票基本信息
- **OCR补充**: 使用RapidOCR自动识别购买方和销售方名称、纳税人识别号
- **全电发票支持**: 支持新版全电发票格式解析
- **实时显示**: 识别一条显示一条，无需等待全部完成
- **结果可编辑**: 双击单元格可编辑识别结果
- **文件快速打开**: 双击文件名可用系统默认程序打开原文件
- **Excel导出**: 识别结果可导出为Excel文件，支持选择导出字段
- **安全确认**: 删除文件、清空列表、清空结果等操作均有确认提示
- **日志查看**: 可查看详细的识别日志，便于排查问题

## 安装

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. OCR模型

首次运行时会自动下载RapidOCR模型，请确保网络畅通。

## 使用方法

### 启动程序

双击 `启动.bat` 或运行：

```bash
python invoice_app.py
```

### 操作步骤

1. **添加文件**: 点击"添加文件"或"添加文件夹"按钮，选择发票文件
2. **开始识别**: 点击"开始识别"按钮，程序会自动识别二维码并解析发票信息
   - 自动跳过已识别的文件
   - 新结果追加到现有结果列表
3. **查看结果**: 识别结果实时显示在下方表格中
4. **编辑结果**: 双击单元格可编辑识别结果
5. **打开文件**: 双击文件名可打开原发票文件
6. **查看日志**: 点击"查看日志"按钮查看详细识别过程
7. **导出Excel**: 点击"导出Excel"按钮，选择需要导出的字段，保存为Excel文件
8. **清空结果**: 点击"清空结果"按钮可清空所有识别结果（需确认）

## OCR识别优化

程序使用以下图像预处理技术提高OCR识别准确度：

1. **灰度转换**: 将彩色图像转为灰度图
2. **CLAHE增强**: 自适应直方图均衡化，增强对比度
3. **降噪处理**: 使用非局部均值降噪去除噪点
4. **二值化**: 使用OTSU自动阈值二值化
5. **锐化处理**: 使用拉普拉斯算子锐化边缘

## 新功能说明

### 智能追加模式

- 识别新文件时，自动检测是否已识别过
- 已识别的文件会被跳过，避免重复工作
- 新识别的结果追加到现有结果列表，不会覆盖之前的数据
- 支持多次添加文件并识别，累积结果

### 安全操作确认

以下操作需要用户确认：
- **删除选中文件**: 显示选中的文件数量
- **清空文件列表**: 显示当前文件数量
- **清空识别结果**: 显示当前记录数量

### 详细日志

- 每个文件的识别过程都有详细日志
- 包括二维码识别、XML解析、OCR识别等各步骤
- 可查看单个文件的识别日志（双击"查看日志"列）
- 可查看所有文件的识别日志（点击"查看日志"按钮）

## 注意事项

1. **二维码识别**: 确保发票二维码清晰可见，模糊或遮挡可能导致识别失败
2. **OCR识别**: OCR识别需要一定时间，大批量处理请耐心等待
3. **重复文件**: 程序会自动跳过已识别的文件，无需手动筛选
4. **结果保存**: 识别结果会累积保存，如需重新开始请点击"清空结果"
5. **发票查验**: 如需在线查验发票真伪，请访问国家税务总局发票查验平台
